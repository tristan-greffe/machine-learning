GeoML ​

GeoML est un projet appliqué de machine learning géospatial : entraîner des modèles de détection d'objets sur de vraies images aériennes, les exporter en ONNX, et livrer un SPA 100 % statique qui exécute l'inférence directement dans le navigateur, sans backend.

  • Un SPA React pilote la carte (MapLibre) et exécute l'inférence localement via ONNX Runtime Web. Les couches de tuiles (IGN WMTS, OSM …) sont appelées directement depuis le navigateur.
  • Un pipeline d'entraînement offline télécharge des tuiles satellitaires IGN et des polygones BD TOPO/OSM, génère automatiquement un dataset annoté au format YOLO, affine un modèle YOLOv8, et exporte les poids .onnx intégrés au SPA.

Pourquoi sans backend

Les modèles YOLOv8n sont suffisamment petits (~12 Mo chacun) pour tourner côté client via WebAssembly.
